Credential Scanner

Scans every line — including fenced bash and yaml blocks — for leaked credentials. Exit code 2 is reserved exclusively for security events and cannot be suppressed.

SUPPRESSION ATTEMPT REJECTED
docs/tutorial.md:41-42
<!-- zenzic:ignore: Z201 -->
✘Finding:GitHub token detected anyway
Why:Z201 is non-suppressible. The directive above is silently rejected — the credential scanner fires unconditionally.
