# Deploy

Export the key before running the release script:
AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE

The deployment guide covers the build, the upload and the verification of the published site, in that order, with one command per step and a check after each so that a failure is caught where it happens rather than at the end of the run.
