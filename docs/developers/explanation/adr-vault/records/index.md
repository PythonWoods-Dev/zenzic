# ADR Records

This directory holds the individual Architecture Decision Record files —
one Markdown page per decision, named after the choice it documents rather
than a bare sequence number. It has no categorization or reading order of
its own.

Start at the [ADR Vault](../index.md) instead: it groups every record by
genesis, core architecture, or documentation-site decisions, and explains
the Context/Decision/Rationale/Invariants/Consequences structure each one
follows.
