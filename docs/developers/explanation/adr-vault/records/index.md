# ADR Records Vault

The official repository of Architecture Decision Records (ADRs) for the Zenzic ecosystem. Each record captures a critical architectural choice, its context, design options considered, and the binding operational consequences for the codebase.

Browse the individual decision records listed in this directory, or view the [ADR Vault Overview](../index.md).
