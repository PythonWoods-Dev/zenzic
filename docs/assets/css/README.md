# Tailwind CSS External Build Artifact

---

## Protocol

`zenzic-tailwind.min.css` is an **external build artifact** produced by a human-run
Tailwind CLI v4 process. It is **not generated by CI** (Pillar 3: Zero Subprocess).

---

## Build Instructions (Human Operator Only)

```bash
# Prerequisites: Node.js locally (NOT in CI). The version is pinned in
# package.json, so install from it rather than letting npx resolve whatever is
# current on the day:
npm install                 # installs @tailwindcss/cli at the locked version
# npm 12 defaults `allow-remote` to "none" and one of Tailwind's optional
# platform packages is fetched as a remote tarball, so the first resolution
# needs `--allow-remote=all`. Installing from the committed lockfile does not.
npm run build:css           # -i tailwind-input.css -o docs/assets/css/zenzic-tailwind.min.css --minify
```

**Why the version is pinned.** The committed bundle declares its own builder in
its first comment — `tailwindcss v4.3.1` — and nothing else recorded it, so
`npx @tailwindcss/cli` would have resolved to whatever was current and produced a
different 44 KB artifact. `package.json` pins `@tailwindcss/cli` at `4.3.1`
exactly, with no range.

**The build stays human-operated and CI still installs nothing from here.** This
package manifest is not a runtime dependency: the Python package ships no
JavaScript.

!!! warning "A class that is not in the bundle compiles to nothing"

    Utilities are generated from what the templates use at build time, so a class
    added to a partial without rebuilding produces **no CSS at all** — silently.
    It has happened twice: `dark:bg-[var(--zz-surface-0)]/30` (Tailwind cannot
    apply an opacity modifier to an arbitrary `var()` colour) left a panel light
    on a dark page, and `pt-24`/`pb-16`/`pb-24`/`pb-10` would have removed padding
    and added none. **Check a new class against the compiled file before relying
    on it**, or rebuild.

---

## Critical Constraints

- **Preflight DISABLED:** The CSS Reset (Preflight) must be disabled in `tailwind-input.css`
  via `@layer base {}` override or `preflight: false` in Tailwind config, to prevent
  interference with Zensical/MkDocs Material base typography.
- **Commit the output:** After building locally, commit `zenzic-tailwind.min.css` to the
  repository. CI will serve it as a static file.
- **`just build-docs` enforces presence:** The build target fails with `exit 1` if this
  file does not exist before invoking `uvx uv run mkdocs build`.
