# Editor & LSP Integration Guides

Guides and operational references for using Zenzic within modern code editors. Zenzic includes a native Language Server Protocol (LSP) implementation that provides real-time inline diagnostics, sub-50ms keystroke evaluation, workspace status bar indicators, and automated Quick Fixes directly inside your editing environment.

Learn how to configure the [VS Code Extension](vscode.md) or integrate with other LSP clients.
