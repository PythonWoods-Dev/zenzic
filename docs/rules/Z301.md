# Z301: DANGLING_REF

<div class="grid cards" markdown>

- :material-alert-outline:{ .lg .middle style="color: #f59e0b;" } **Severity: Warning**

    ---

    Penalty: **4.0 points** | Category: **`navigation`**

- :material-cog-sync-outline:{ .lg .middle style="color: #64748b;" } **Remediation & Opt-In**

    ---

    Auto-Fixable: **No** | Opt-In: **No**

## Rationale

This rule is emitted when a full-form reference link (for example, `[heading][my-ref]`, or its collapsed variant `[my-ref][]`) has no matching definition `[my-ref]: URL` anywhere in the document. A bare shortcut reference (`[my-ref]` with no trailing `[...]`) is not checked by this rule.

As a warning, this finding is non-blocking by default and only fails the build under `--strict` — the identifier is still worth fixing (a dangling reference degrades navigation), but it does not indicate the same severity as a broken link (`Z101`).

---

## How to Fix

Inspect the flagged location in the Markdown file and update the content or configuration:

<div class="grid cards" markdown>

- :material-close-circle:{ .lg .middle style="color: #ef4444;" } **Failing Pattern (Triggers Z301)**

    ---

    ```markdown title="docs/example.md"
    <!-- BAD: [install-guide] shortcut has no definition at bottom -->
    Follow our [Installation Guide][install-guide] to begin.
    ```

- :material-check-circle:{ .lg .middle style="color: #10b981;" } **Passing Pattern (Resolves Z301)**

    ---

    ```markdown title="docs/example.md"
    <!-- GOOD: Include matching reference definition line -->
    Follow our [Installation Guide][install-guide] to begin.

    [install-guide]: ../how-to/install.md
    ```

</div>
