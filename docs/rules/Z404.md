## Rationale

This rule is emitted when a static theme or infrastructure asset path declared in engine configuration (such as `extra_css` or `favicon` in `mkdocs.yml`) cannot be found on the filesystem disk.

---

## How to Fix

Inspect the flagged location in the Markdown file and update the content or configuration:

---

## Configuration

```yaml
# Governed by asset paths in mkdocs.yml
```

---

## Suppression & Governance

Because `Z404` is a configuration-level infrastructure asset rule, it **CANNOT** be suppressed via inline comments (`<!-- zenzic:ignore: Z404 -->`).

Correct the asset path in your site configuration file (e.g. `mkdocs.yml`), or place the missing asset file at the declared location.
