## Rationale

Non-suppressible security code — `<!-- zenzic:ignore:Z205 -->` is silently rejected. A forbidden URI scheme (`javascript:` or `data:`) always maps to `security_breach` severity and Exit 2, with a DQS Security Override (score collapses to 0/100), representing a potential XSS security risk.

---

## How to Fix

Remove `javascript:` or `data:` schemes from links and replace them with standard HTTP/HTTPS URLs or internal relative links.
