# Z601: BRAND_OBSOLESCENCE

<div class="grid cards" markdown>

- :material-alert-outline:{ .lg .middle style="color: var(--zz-warning);" } **Severity: Warning**

    ---

    Penalty: **2.0 points** | Category: **`brand`**

- :material-cog-sync-outline:{ .lg .middle style="color: var(--zz-terminal-meta);" } **Remediation & Opt-In**

    ---

    Auto-Fixable: **No** | Opt-In: **No**

## Rationale

This governance rule is triggered when deprecated brand terms, legacy product names, or obsolete terminology are found within documentation prose.

---

## How to Fix

Inspect the flagged location in the Markdown file and update the content or configuration:

<div class="grid cards zz-pattern-pair" markdown>

- :material-close-circle:{ .lg .middle style="color: var(--zz-error);" } **Failing Pattern (Triggers Z601)**

    ---

    ```markdown title="docs/example.md"
    <!-- BAD: Referencing legacy product name -->
    The LegacyDocTool static analyzer checks link graphs.
    ```

- :material-check-circle:{ .lg .middle style="color: var(--zz-success);" } **Passing Pattern (Resolves Z601)**

    ---

    ```markdown title="docs/example.md"
    <!-- GOOD: Using current official product branding -->
    The Zenzic static analyzer checks link graphs.
    ```

</div>

```toml title="pyproject.toml"

```

---

## Suppression

Suppress an intentional mention (e.g. a migration guide or changelog entry that must reference the legacy name) with an inline comment:

```markdown
<!-- zenzic:ignore:Z601 -->
```

MDX files use the equivalent block-comment form:

```mdx
{/* zenzic:ignore:Z601 */}
```
