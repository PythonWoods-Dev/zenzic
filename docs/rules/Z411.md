## Description

The document has no outgoing links and forms a structural dead end in the documentation graph.

A Dead End (Z411) occurs when a Markdown/MDX page does not link to any other resources. In a well-structured documentation graph, every page should ideally guide the user to further reading, related topics, or back to a main index. A page with zero outgoing links strands the reader.

Terminal assets like images, CSS files, and PDFs are excluded from this rule.

---

## How to Fix

Add relevant outgoing links to the document to connect it to the rest of the documentation graph:

1. Link to related concepts or further reading.
2. Link to a parent or index page to provide a path back.

---

## Configuration

`Z411` is opt-in. Enable it under `[policies]`:

```toml title=".zenzic.toml"
[policies]
enable_dead_end_check = true
```

```toml title="pyproject.toml"
[tool.zenzic.policies]
enable_dead_end_check = true
```

---

## Suppression & Governance

Because `Z411` is a global graph topology rule evaluated across the Virtual Site Map, it **CANNOT** be suppressed via inline comments (`<!-- zenzic:ignore: Z411 -->`) — this is enforced by `NON_INLINE_SUPPRESSIBLE_CODES` (ADR-093). If you add an inline directive anyway, `Z411` still fires and the dead directive itself is reported as `Z603 DEAD_SUPPRESSION`, pointing you back here.

If the document is intentionally designed as a dead end (for example, a terminal legal disclaimer or an auto-generated changelog with no internal references), configure suppression in `.zenzic.toml` using `directory_policies` or `per_file_ignores`:

### Option 1: Directory Policies (`.zenzic.toml`)

```toml
[governance.directory_policies]
"legal/**" = ["Z411"]
```

### Option 2: Per-File Ignores (`.zenzic.toml`)

```toml
[governance.per_file_ignores]
"docs/legal/disclaimer.md" = ["Z411"]
```

### Track 2: `pyproject.toml`

```toml
[tool.zenzic.governance.directory_policies]
"legal/**" = ["Z411"]

[tool.zenzic.governance.per_file_ignores]
"docs/legal/disclaimer.md" = ["Z411"]
```
