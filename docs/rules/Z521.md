## Description

A Markdown table is missing one or more mandatory column headers required by your project's `[policies].required_table_columns` configuration.

In Specification-Driven Development (SDD), tables often represent formal data contracts (such as API route definitions, schema field descriptions, or test matrices). Missing columns break downstream tooling, automated scrapers, and developer comprehension.

---

## Configuration

Enable column requirements globally or scoped under specific heading contexts in `.zenzic.toml`:

```toml
[policies.required_table_columns]
"*" = ["Status", "Description"]
"^API Reference$" = ["Method", "Endpoint", "Auth"]
```

- `*` enforces the column list across all Markdown tables in the documentation.
- Regex heading patterns (e.g. `^API Reference$`) scope the requirement exclusively to tables placed beneath that heading.

---

## How to Fix

Add the missing column header(s) to the table header and separator rows:

```markdown
<!-- Before (Missing Status column) -->
| Endpoint | Method |
| :--- | :--- |
| /users | GET |

<!-- After (Compliant table) -->
| Endpoint | Method | Status |
| :--- | :--- | :--- |
| /users | GET | `stable` |
```
