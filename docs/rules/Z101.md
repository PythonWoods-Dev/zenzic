# Z101: LINK_BROKEN

<div class="grid cards" markdown>

- :material-alert-circle:{ .lg .middle style="color: #e11d48;" } **Severity: Error**

    ---

    Penalty: **8.0 points** | Category: **`structural`**

- :material-cog-sync-outline:{ .lg .middle style="color: #64748b;" } **Remediation & Opt-In**

    ---

    Auto-Fixable: **No** | Opt-In: **No**

</div>

## Rationale

This rule validates every relative Markdown link against the Virtual Site Map (VSM) rather than just checking filesystem disk presence. A finding is emitted when a target page does not exist in the VSM or is unserved by the build engine.

Linking to non-existent target files or unrendered routes produces broken HTTP 404 navigation errors for end users upon site publication.

---

### `data-zenzic-ignore` does not suppress it

`Z101` is decided against the Virtual Site Map, which is a fact about the whole
project rather than about one tag, so the `data-zenzic-ignore` attribute does not
reach it — a tag carrying the attribute still raises `Z101` when its target is not
in the map. The same tag's `Z104` **is** suppressed by it, so one missing target
can leave one of its two codes reported:

```html
<!-- Z104 suppressed, Z101 still reported -->
<a href="./gone.html" data-zenzic-ignore>Gone</a>
```

Use an inline `<!-- zenzic:ignore: Z101 -->` comment on the same line, or
`.zenzic.toml` governance, to silence `Z101` itself. A directive that silences
nothing is reported as [`Z603`](Z603.md).

---

## How to Fix

Inspect the flagged location in the Markdown file and update the content or configuration:

<div class="grid cards" markdown>

- :material-close-circle:{ .lg .middle style="color: #ef4444;" } **Failing Pattern (Triggers Z101)**

    ---

    ```markdown title="docs/example.md"
    <!-- BAD: Linking to a non-existent file or route -->
    Please refer to our [Installation Guide](../setup/installation.md) for details.
    ```

- :material-check-circle:{ .lg .middle style="color: #10b981;" } **Passing Pattern (Resolves Z101)**

    ---

    ```markdown title="docs/example.md"
    <!-- GOOD: Linking to an existing, served page in the VSM -->
    Please refer to our [Installation Guide](../how-to/install.md) for details.
    ```

</div>

## Configuration

```toml title=".zenzic.toml"
# .zenzic.toml - Exclude specific external domain URLs from broken link checks
excluded_external_urls = [
    "https://github.com/PythonWoods/zenzic",
]
```

```toml title="pyproject.toml"
[tool.zenzic]
excluded_external_urls = [
    "https://github.com/PythonWoods/zenzic",
]
```
