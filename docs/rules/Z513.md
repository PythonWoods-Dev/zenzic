# Z513: DUPLICATE_HEADING

<div class="grid cards" markdown>

- :material-alert-outline:{ .lg .middle style="color: #f59e0b;" } **Severity: Warning**

    ---

    Penalty: **2.0 points** | Category: **`content`**

- :material-cog-sync-outline:{ .lg .middle style="color: #64748b;" } **Remediation & Opt-In**

    ---

    Auto-Fixable: **No** | Opt-In: **No**

</div>

---

## Description

Two or more headings in the same document resolve to identical text (ignoring case and whitespace).

Duplicate headings create ambiguous slug anchors (e.g. `#section` vs `#section-1`), breaking deep links and confusing document outline navigation.

---

## How to Fix

Rename headings so that every section has a unique, descriptive title.

---

## Suppression

If duplicate headings are required by design, suppress the warning with an inline comment:

The directive belongs **at the end of the line the finding is on**. Placed on the
line above it suppresses nothing and is itself reported as
[`Z603 DEAD_SUPPRESSION`](Z603.md). MDX files accept the JSX comment form as well,
and the two behave identically — same placement, same effect:

```markdown title="Markdown"
<!-- zenzic:ignore:Z513 -->
```

```markdown title="MDX"
{/* zenzic:ignore:Z513 */}
```
