## Description

A document's structural complexity score exceeds the maximum allowed threshold configured in `[policies].max_document_complexity`.

Document complexity measures cognitive load based on prose word count, heading depth, and link density. Excessively complex pages are difficult for readers to digest and maintain.

---

## How to Fix

Refactor or split the document into smaller, modular topics linked together through a table of contents or conceptual guides.

---

## Configuration

Set the complexity ceiling in `.zenzic.toml`:

```toml
[policies]
max_document_complexity = 5
```

The example below is measured against this ceiling: the fixture's document
exceeds a complexity of 5 and is silent at 50, so a card documenting 50 would
have shown an example its own configuration suppresses.

---

## Suppression

Suppress with an inline comment:

The directive belongs **at the end of the line the finding is on**. Placed on the
line above it suppresses nothing and is itself reported as
[`Z603 DEAD_SUPPRESSION`](Z603.md). MDX files accept the JSX comment form as well,
and the two behave identically — same placement, same effect:

```markdown title="Markdown"
<!-- zenzic:ignore:Z619 -->
```

```markdown title="MDX"
{/* zenzic:ignore:Z619 */}
```
