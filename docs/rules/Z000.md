## Rationale

This rule is emitted during configuration initialization when `.zenzic.toml` specifies an `engine` identifier that is unknown, deprecated, or no longer supported by the Zenzic Core Engine.

Operating with an unsupported engine identifier breaks Virtual Site Map (VSM) route resolution, routing plugins, and navigation tree compilation because Zenzic cannot instantiate the matching AST build adapter.

---

## How to Fix

Correct or remove the unsupported `engine` value in `.zenzic.toml` (or the equivalent `[tool.zenzic.build_context]` table in `pyproject.toml`) as indicated by the diagnostic message, using one of the currently supported identifiers below. This rule fires during configuration initialization, before any Markdown file is read.

---

## Configuration

```toml title=".zenzic.toml"
[build_context]
# Supported values: "mkdocs", "zensical", "standalone", "prebuilt", "vsm", or "auto" to auto-discover
engine = "mkdocs"
```

```toml title="pyproject.toml"
[tool.zenzic.build_context]
engine = "mkdocs"
```
