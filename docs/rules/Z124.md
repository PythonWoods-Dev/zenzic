## Rationale

Emitted when an HTML element contains blacklisted attributes such as inline event handlers (`onclick`, `onmouseover`) or shadow routing attributes.

---

## How to Fix

Remove inline event handlers or blacklisted script attributes from documentation HTML tags, or use `data-zenzic-ignore` to suppress an intentionally opaque context.
