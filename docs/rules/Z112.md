## Rationale

An entry in the `absolute_path_allowlist` configuration was never matched by any scanned absolute path link. This indicates that the entry is stale and no longer needed.

Stale allowlist entries accumulate configuration debt: each entry deliberately bypasses `Z105` (ABSOLUTE_PATH) checking, so an unused entry is a silent, unexercised exception that no longer protects any real link.

---

## How to Fix

Inspect the flagged location in the configuration file and update the content or configuration:

<div class="grid cards" markdown>

- :material-close-circle:{ .lg .middle style="color: #ef4444;" } **Failing Pattern (Triggers Z112)**

    ---

    ```toml title=".zenzic.toml"
    # BAD: entry never matched by any scanned absolute path link
    absolute_path_allowlist = ["/legacy/path/"]
    ```

- :material-check-circle:{ .lg .middle style="color: #10b981;" } **Passing Pattern (Resolves Z112)**

    ---

    ```toml title=".zenzic.toml"
    # GOOD: entry removed once no link references it
    absolute_path_allowlist = []
    ```

</div>
