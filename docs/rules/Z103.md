## Rationale

This rule is triggered when a link references a Markdown file that exists on the local filesystem disk but is omitted from the site navigation tree (`mkdocs.yml`).

While the target file is physically present, it is absent from the navigation tree. A reader who follows the link arrives on a real page with no menu path back to the rest of the site.

### Why Zenzic reports this and MkDocs does not

`Z103` is **Zenzic's own position, not an implementation of a generator setting.** MkDocs emits no diagnostic for a link into an out-of-nav page: such a page is `InclusionLevel.INCLUDED`, and the link-validation code (`structure/pages.py`) downgrades a warning only when the target is *excluded* (`exclude_docs`/`draft_docs`), which an out-of-nav page is not. Verified by execution against MkDocs 1.6.1: a site whose `index.md` links to a `not_in_nav` page builds clean under `--strict`, exit `0`.

Zenzic reports it anyway, because arriving somewhere with no way onward is a defect for the reader even when the build is silent. That MkDocs does not flag it is MkDocs' gap, and the judgement is ours to own rather than to attribute upstream.

`Z103` and [`Z402`](Z402.md) are the same editorial situation seen from two sides — the link that reaches the page, and the page itself. They are separate codes because the fix differs: `Z402` is answered by declaring the page's absence from the nav deliberate, `Z103` by making the target reachable or removing the link. When a page is declared out-of-nav via MkDocs' `not_in_nav`, Zenzic treats it as reachable-by-intent, and **both** findings stop firing — the target is no longer an orphan, so links into it are no longer orphan links.

## How to Fix

Inspect the flagged location in the Markdown file and update the content or configuration:

<div class="grid cards zz-pattern-pair" markdown>

- :material-close-circle:{ .lg .middle style="color: var(--zz-error);" } **Failing Pattern (Triggers Z103)**

    ---

    ```markdown title="docs/guide/example.md"
    <!-- BAD: Linking to an unlisted draft file -->
    Check the [Draft Architecture](../drafts/arch-v2.md).
    ```

- :material-check-circle:{ .lg .middle style="color: var(--zz-success);" } **Passing Pattern (Resolves Z103)**

    ---

    ```markdown title="docs/guide/example.md"
    <!-- GOOD: Link to a file registered in site navigation -->
    Check the [Architecture Explanation](../explanation/architecture.md).
    ```

</div>

## Configuration

```yaml
# mkdocs.yml - Ensure target document is listed under nav
nav:
  - Architecture: explanation/architecture.md
```
