## Description

A target document matches a configured traceability path pattern, but possesses no inbound links from the required source document namespaces defined in `[policies].traceability_targets`.

In systems engineering and Specification-Driven Development (SDD), specifications, requirements, or architecture decision records must be bidirectionally traceable to higher-level architecture documents or parent epics. An untraceable specification represents an isolated artifact disconnected from system governance.

---

## Configuration

Map target document glob patterns to lists of required inbound source globs in `.zenzic.toml`:

```toml
[policies.traceability_targets]
"specs/**" = ["architecture/**", "epics/**"]
"adrs/**" = ["rfcs/**"]
```

### Configuration — Track 2 (`pyproject.toml`)

```toml
[tool.zenzic.policies.traceability_targets]
"specs/**" = ["architecture/**", "epics/**"]
"adrs/**" = ["rfcs/**"]
```

---

## How to Fix

Add a link to the target document from at least one document residing in the required source namespaces:

```markdown
<!-- In docs/architecture/overview.md -->
For detailed protocol mechanics, see the [SDD Specification](../specs/sdd.md).
```

## Suppression & Governance

Because `Z412` is a global graph topology rule evaluated across the Virtual Site Map at the repository boundary, it **CANNOT** be suppressed via inline comments (`<!-- zenzic:ignore: Z412 -->`) — this is enforced by `NON_INLINE_SUPPRESSIBLE_CODES` (ADR-093). If you add an inline directive anyway, `Z412` still fires and the dead directive itself is reported as `Z603 DEAD_SUPPRESSION`, pointing you back here.

It can **ONLY** be suppressed through governance configuration in `.zenzic.toml` using `directory_policies` or `per_file_ignores`:

### Option 1: Directory Policies (`.zenzic.toml`)

```toml
[governance.directory_policies]
"specs/experimental/**" = ["Z412"]
```

### Option 2: Per-File Ignores (`.zenzic.toml`)

```toml
[governance.per_file_ignores]
"specs/standalone.md" = ["Z412"]
```

### Suppression — Track 2 (`pyproject.toml`)

```toml
[tool.zenzic.governance.directory_policies]
"specs/experimental/**" = ["Z412"]

[tool.zenzic.governance.per_file_ignores]
"specs/standalone.md" = ["Z412"]
```
