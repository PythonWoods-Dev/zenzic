## Rationale

This rule is an informational diagnostic emitted in standalone directory mode when a documentation subfolder contains topic files but lacks a primary index file (`index.md` or `README.md`).

## Configuration

`Z401` is opt-in. Enable it under `[policies]`:

```toml title=".zenzic.toml"
# Informational diagnostic; no points deducted from DQS
[policies]
enable_directory_index_check = true
```

---

## Suppression & Governance

Because `Z401` is a structural topology rule evaluated across documentation directories, it **CANNOT** be suppressed via inline comments (`<!-- zenzic:ignore: Z401 -->`) — this is enforced by `NON_INLINE_SUPPRESSIBLE_CODES` (ADR-093). If you add an inline directive anyway, `Z401` still fires and the dead directive itself is reported as `Z603 DEAD_SUPPRESSION`, pointing you back here.

To suppress `Z401` for specific directories, configure `directory_policies` in `.zenzic.toml`:

```toml
[governance.directory_policies]
"notes/**" = ["Z401"]
```
