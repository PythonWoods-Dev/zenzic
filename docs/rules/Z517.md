## Description

A heading ends with trailing punctuation such as a period (`.`), colon (`:`), or semicolon (`;`).

Headings serve as labels and document outline nodes; ending them with sentence-terminating punctuation compromises typographical consistency. Question marks (`?`) and exclamation points (`!`) are permitted when appropriate.

---

## How to Fix

Remove the trailing period, colon, or semicolon from the heading.

Run `zenzic fix --apply` to automatically remove trailing punctuation from headings across your documentation.

---

## Configuration

`Z517` is opt-in. Enable it under `[policies]`:

```toml title=".zenzic.toml"
[policies]
enable_heading_punctuation_check = true
```

```toml title="pyproject.toml"
[tool.zenzic.policies]
enable_heading_punctuation_check = true
```

## Suppression

Suppress with an inline comment:

The directive belongs **at the end of the line the finding is on**. Placed on the
line above it suppresses nothing and is itself reported as
[`Z603 DEAD_SUPPRESSION`](Z603.md). MDX files accept the JSX comment form as well,
and the two behave identically — same placement, same effect:

```markdown title="Markdown"
<!-- zenzic:ignore:Z517 -->
```

```markdown title="MDX"
{/* zenzic:ignore:Z517 */}
```
