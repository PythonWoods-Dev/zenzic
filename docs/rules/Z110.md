## Description

The `.zenzic.toml` (or `pyproject.toml`) workspace configuration file contains a malformed TOML syntax error.

When a configuration file is syntactically invalid, Zenzic halts Markdown document analysis to prevent cascading false positives or running with corrupted governance policies.

---

## How to Fix

Fix the TOML syntax error in `.zenzic.toml` indicated in the diagnostic message (such as missing quotes, unclosed brackets, or unescaped characters).

---

## Example Error

```text
# Malformed TOML
placeholder_max_words = [ 50,
```

Corrected `.zenzic.toml`:

```toml
placeholder_max_words = 50
```

---

## Why there is no runnable example

`Z110` is a **configuration-load error** — malformed TOML — on the same path as
[`Z001`](Z001.md). It is raised while the file is parsed, before any Markdown is
read and before a findings payload exists, so the run aborts instead of
reporting. An executable card example requires output to assert against, and
there is none.

A second reason applies to this code specifically: its error panel prints the
**absolute path of the machine that ran it**, so a captured block would encode
one developer's filesystem. The gallery page for this code is deliberately left
as it is for the same reason.
