## Description

A heading level skips one or more levels in the document structure (for example, an `H3` heading immediately follows an `H1` heading without an intervening `H2`).

Skipping heading levels impairs screen reader navigation, breaks document outline generation, and compromises structural accessibility.

---

## How to Fix

Adjust the heading level to maintain sequential hierarchy:

1. Ensure `H2` follows `H1`.
2. Ensure `H3` follows `H2`.

---

## Suppression

If a skipped heading level is intentional, you can suppress this warning using an inline comment directive at the end of the heading line:

The directive belongs **at the end of the line the finding is on**. Placed on the
line above it suppresses nothing and is itself reported as
[`Z603 DEAD_SUPPRESSION`](Z603.md). MDX files accept the JSX comment form as well,
and the two behave identically — same placement, same effect:

```markdown title="Markdown"
<!-- zenzic:ignore:Z510 -->
```

```markdown title="MDX"
{/* zenzic:ignore:Z510 */}
```
