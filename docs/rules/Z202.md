## Rationale

This security rule is triggered when a relative link or asset reference uses parent directory traversal sequences (`../`) to escape the root boundary of the designated documentation workspace (`docs_dir`).

Non-suppressible security code — `<!-- zenzic:ignore:Z202 -->` is silently rejected. Escaping the docs root always triggers Exit 1 with a DQS Security Override (score collapses to 0/100).

---

## How to Fix

Inspect the flagged location in the Markdown file and update the content or configuration:

    ```markdown title="docs/example.md"
    Download [Internal Secret](../../../secrets/keys.json).
    ```

- :material-check-circle:{ .lg .middle style="color: #10b981;" } **Passing Pattern (Resolves Z202)**

    ---

    ```markdown title="docs/example.md"

    Download [Public Keys](../assets/public-keys.json).
    ```
