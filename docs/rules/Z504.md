## Rationale

`Z504` is a **reserved, runtime-inactive code** — it is defined in the Zenzic registry but is not emitted by any check pipeline and has no impact on the Deterministic Quality Score (DQS). It is emitted only by `zenzic diff` when the current DQS is lower than the saved baseline (`.zenzic-score.json`), to identify which commit introduced a regression; it is not itself weighted into the score, since that would be circular.

---

## How to Fix

```bash
# See the score breakdown by category to identify the regression
zenzic score

# After fixing the underlying findings that caused the drop, update the
# baseline on main
zenzic score --save
```

---

## Configuration

`Z504` has no dedicated `.zenzic.toml` configuration key — it reflects the DQS delta between the current run and the saved baseline (`.zenzic-score.json`, written by `zenzic score --save`), not a rule you tune directly.
