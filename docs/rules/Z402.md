## Rationale

This rule is triggered when a Markdown source file resides in the `docs` directory but is not included in the site navigation tree manifest (`mkdocs.yml`). Orphan pages cannot be reached by users browsing site navigation.

## Suppression & Governance

Because `Z402` is a navigation graph topology rule, it **CANNOT** be suppressed via inline comments (`<!-- zenzic:ignore: Z402 -->`) — this is enforced by `NON_INLINE_SUPPRESSIBLE_CODES` (ADR-093). If you add an inline directive anyway, `Z402` still fires and the dead directive itself is reported as `Z603 DEAD_SUPPRESSION`, pointing you back here.

To suppress `Z402` for intentionally unlisted pages (such as landing pages or standalone assets), configure `.zenzic.toml`:

### Option 1: Directory Policies

```toml
[governance.directory_policies]
"standalone/**" = ["Z402"]
```

### Option 2: Per-File Ignores

```toml
[governance.per_file_ignores]
"docs/secret-landing.md" = ["Z402"]
```
