## Rationale

This rule is triggered when a Markdown source file resides in the `docs` directory but is not included in the site navigation tree manifest (`mkdocs.yml`). Orphan pages cannot be reached by users browsing site navigation.

### Declaring a page deliberately absent from the nav (MkDocs)

MkDocs' `not_in_nav` marks pages that are *expected* not to appear in the navigation. Zenzic honours it: a matching page is classified reachable-by-intent and `Z402` does not fire.

```yaml
not_in_nav: |
  includes/*
  developers/explanation/adr-vault/records/*
```

What the key does upstream, read from MkDocs 1.6.1's own source rather than inferred:

- The value is a **gitignore-style pattern list in a single multiline string**. A YAML list is rejected — `Expected a multiline string, but a <class 'list'> was given` — and the build aborts, so Zenzic declares nothing for a list and leaves the finding in place.
- A declared page **is still built and still served**. `not_in_nav` only exempts it from the nav-omission diagnostic (`validation.nav.omitted_files`). Removing a page from the *site* is `exclude_docs` / `draft_docs`, which are different keys.
- Patterns match the docs-root-relative path, so `records/*` covers `records/sub/page.md` too, and `!records/keep.md` re-includes an exception.

Zensical does **not** support `not_in_nav` (its own compatibility documentation lists it under "not yet supported", tracked in its backlog), so this declaration has no effect under the `zensical` engine and the exemption mechanisms below remain the way to express the same intent.

## Suppression & Governance

Because `Z402` is a navigation graph topology rule, it **CANNOT** be suppressed via inline comments (`<!-- zenzic:ignore: Z402 -->`) — this is enforced by `NON_INLINE_SUPPRESSIBLE_CODES` (ADR-093). If you add an inline directive anyway, `Z402` still fires and the dead directive itself is reported as `Z603 DEAD_SUPPRESSION`, pointing you back here.

To suppress `Z402` for intentionally unlisted pages (such as landing pages or standalone assets), configure `.zenzic.toml`:

### Option 1: Directory Policies

```toml
[governance.directory_policies]
"standalone/**" = ["Z402"]
```

### Option 2: Per-File Ignores

```toml
[governance.per_file_ignores]
"docs/secret-landing.md" = ["Z402"]
```
