# Rule Specification Cards

This section contains the official specification cards for all Zenzic static analysis finding codes. Each card documents a rule's severity level, quality score penalty points, DQS taxonomy category (`structural`, `navigation`, `content`, `brand`, or `general` for codes with no scored category), auto-fix availability, opt-in status, design rationale, and step-by-step remediation instructions.

Use the [Finding Codes Index](../reference/finding-codes.md) to view the complete catalog grouped by category, or select a specific rule card below to review its technical specification.
