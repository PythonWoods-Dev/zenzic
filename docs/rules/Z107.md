## Rationale

This rule is emitted when a link sits **inside the very section its fragment names** and its visible text slugifies to that same fragment — a self-loop that takes the reader exactly where they already are. A link whose text happens to match its target but which lives in a *different* section is ordinary cross-reference navigation and is never flagged; neither is a link that appears before the page's first heading, because there is no enclosing section for it to loop within.

---

## How to Fix

Inspect the flagged location in the Markdown file and update the content or configuration:

<div class="grid cards zz-pattern-pair" markdown>

- :material-close-circle:{ .lg .middle style="color: var(--zz-error);" } **Failing Pattern (Triggers Z107)**

    ---

    ```markdown title="docs/example.md"
    ## Installation

    <!-- BAD: the link sits inside the section it points at -->
    See [installation](#installation) for the steps.
    ```

- :material-check-circle:{ .lg .middle style="color: var(--zz-success);" } **Passing Pattern (Resolves Z107)**

    ---

    ```markdown title="docs/example.md"
    ## Configuration

    <!-- GOOD: the link points at a different section -->
    See [installation](#installation) for the steps.
    ```

</div>
