## Rationale

`Z104` is defined in the finding-codes catalog to describe a document that
references a local file (a Markdown page, binary, or image asset such as a
PDF, ZIP archive, or PNG) using a relative path, where the target is missing
from the local workspace filesystem. The current engine consolidates this
condition under the shared **`Z101` LINK_BROKEN** code rather than emitting
`Z104` — missing-file links surface as `Z101`, alongside broken external
links and other unreachable-link conditions (see [`Z101`](Z101.md)).

---
