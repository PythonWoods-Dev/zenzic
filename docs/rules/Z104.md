## Rationale

`Z104` is reserved for static-asset existence checks: a relative link to a
binary or image asset (PDF, ZIP archive, PNG, and similar) that is missing
from the local workspace filesystem. This is validated directly against disk
by the asset-checking branch of the incremental analysis engine, distinct
from **`Z101` LINK_BROKEN**, which validates relative links to Markdown pages
against the Virtual Site Map (VSM) rather than the filesystem (see
[`Z101`](Z101.md)). A missing Markdown page target surfaces as `Z101`, not
`Z104` — only missing static assets emit `Z104`.
