# Core & Configuration Scenarios (Z0xx)

Interactive lab scenarios and test fixtures for core initialization and configuration error codes (`Z0xx`). These examples illustrate how Zenzic detects malformed `.zenzic.toml` configuration files, invalid schema declarations, and initialization errors.

Run `zenzic lab z001` to test these scenarios interactively, or return to the [Lab Gallery Overview](../index.md).
