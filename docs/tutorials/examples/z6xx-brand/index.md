# Governance & Brand Scenarios (Z6xx)

Interactive lab scenarios and test fixtures for governance and brand rules (`Z6xx`). These fixtures demonstrate brand obsolescence detection (`Z601`), dead suppression comments (`Z603`), Policy-as-Code frontmatter enforcement (`Z610`–`Z616`), and stale global suppressions (`Z620`).

Run `zenzic lab z601` to test governance scenarios interactively, or return to the [Lab Gallery Overview](../index.md).
