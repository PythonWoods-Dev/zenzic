# Content Quality Scenarios (Z5xx)

Interactive lab scenarios and test fixtures for content quality rules (`Z5xx`). These fixtures demonstrate placeholder text detection (`Z501`), short content warnings (`Z502`), code snippet errors (`Z503`), untagged code blocks (`Z505`), and malformed frontmatter (`Z506`).

Run `zenzic lab z501` to test content quality scenarios interactively, or return to the [Lab Gallery Overview](../index.md).
