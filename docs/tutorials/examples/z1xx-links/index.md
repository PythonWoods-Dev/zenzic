# Link Integrity Scenarios (Z1xx)

Interactive lab scenarios and test fixtures for link integrity finding codes (`Z1xx`). These fixtures demonstrate detection of broken internal links, missing target anchors, orphan links, absolute path violations, circular links, and broken external HTTP references.

Run `zenzic lab z101` to test these scenarios interactively, or return to the [Lab Gallery Overview](../index.md).
