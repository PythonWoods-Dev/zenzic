# Guide

This guide page exists on disk so that `[](guide.md)` in `index.md` does not
trigger a Z101 LINK_BROKEN finding — only Z108 EMPTY_LINK_TEXT fires.

Descriptive link labels help every reader, not only those using assistive
technology, because they let a reader scanning a page understand a link's
destination without following it. See the [gallery index](index.md) for
more about this finding.
