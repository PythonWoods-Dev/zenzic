# Generic Alt Text Example

![image](assets/logo.png)

This page triggers Z514 due to generic alt text. Descriptive alt text lets
screen readers convey what an image actually shows, instead of a filler word
that tells assistive technology nothing about the image's content or purpose.
See the [WCAG non-text content guideline](https://www.w3.org/WAI/WCAG22/Understanding/non-text-content.html)
for the full accessibility rationale.
