# Getting Started

This page is the entry point of a two-page loop. It links to the setup guide,
and the setup guide links straight back here, so a reader following the trail
returns to where they began without reaching anything new along the way.

The loop is deliberate here, because reciprocal navigation between a guide and
the page that introduces it is a common and reasonable structure. What matters
is that the analyser can see the shape and say so, rather than leaving a reader
to discover it by walking in a circle.
