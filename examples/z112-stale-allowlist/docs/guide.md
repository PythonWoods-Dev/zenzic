# Guide

This guide page exists to demonstrate clean link integrity (no Z101 findings).

Keeping an allowlist synchronized with the links actually present in a
project avoids exactly the kind of silent configuration rot that Z112
detects. See the [index page](index.md) for the stale-entry scenario this
fixture demonstrates, and for how Zenzic surfaces the unused entry as a
warning against the configuration file itself rather than any document.
