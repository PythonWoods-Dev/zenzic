# Documentation

Welcome to the project documentation. This guide covers all aspects of
installation, configuration, and everyday usage for new and experienced users.

## API Reference

The architecture is summarised in the diagram below, which is referenced here
and is not present on disk:

![Architecture overview](assets/architecture.png)

A missing asset is a different failure from a missing page. The link resolves to
a file the build will try to copy, so the page renders and the image does not —
a defect a reader sees and a link checker looking only at Markdown targets does
not report.

## Getting Started

Install the package with your preferred package manager and follow the setup
wizard. Detailed instructions are available in the installation section.
